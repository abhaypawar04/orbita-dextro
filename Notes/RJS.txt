Let / var / const 👍
They are all used to declare variables:
Prefer const by default. Use let when the value needs to change. Avoid var in modern code unless you specifically need its behavior. 

var

JavaScript has function scope and block scope. 
A block is anything inside { }

let IS block scoped

const is also block scoped

var is function scoped. 
Function test ()
{
var x = 10; console.log(x); 
}
test(); //10 
console.log(x); // reference error 
So var is accessible throughout the function, but not outside the function. 

let and const are block scoped

    }

}
//The variables only exist inside the if block.

B) Primitive vs Reference Types in JavaScript 
JavaScript values are commonly taught as primitive values vs objects (often informally called "reference types"). 

let name = "Rahul";       	 // string
let age = 21;            		 // number
let price = 99.99;       		 // number
let big = 123456789n;    	 // bigint
let isLoggedIn = true;   	 // boolean
let x;                   		 // undefined
let data = null;         		 // null
let id = Symbol("id");   	 // symbol

A primitive value is a single, immutable value. 
let x = "hello"; //"hello" itself cannot be modified. You can make x refer to another string: x = "world"; 
But you didn't modify "hello". You replaced the value associated with x.
Unlike primitive values, objects can generally be modified. 
const user = {
    name: "Rahul",
    age: 21
};
user.age = 22;

console.log(user);  //    {name: "Rahul", age: 22}

But this is true
const a = { name: "Rahul" };
const b = a;

console.log(a === b); // Output:true

Q1

const b = {};
console.log(a === b); //false Because they're two separate objects. 

Q2 
const a = {};
const b = a;
console.log(a === b); //true Because they're the same object.

VERY IMPORTANT: JavaScript is pass-by-value 
For an object, the value being copied is the reference to the object.

"What's the difference between primitive and reference types?", a strong answer is:
Primitive values are immutable values such as strings, numbers, booleans, bigint, undefined, null, and symbols. When a primitive is assigned to another variable, the value is copied, so changing one variable doesn't affect the other. Objects—including arrays and functions—are mutable values. When an object is assigned to another variable, the reference to the same object is copied, so both variables can access and modify that same object. Technically, JavaScript uses pass-by-value; for objects, the value being copied is the reference to the object.

Explicit coercion
